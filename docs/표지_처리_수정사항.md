# 표지 처리 규칙 수정 완료

## 수정된 문제점

1. **잘못된 자르기 방향**
   - 문제: 왼쪽 50%를 자르고 있었음
   - 해결: 오른쪽 50%를 사용하도록 수정

2. **전역 설정으로 인한 모든 썸네일 자르기**
   - 문제: settings.json에 `crop_left_half: true`가 전역 설정되어 모든 썸네일이 잘림
   - 해결: 전역 설정 제거, 표지 파일만 개별 처리

## 수정 내용

### 1. pdf_processor.py - 표지 감지 로직 개선
```python
# 표지 파일만 플래그 설정 (전역 설정 사용 안 함)
if re.search(r'표지|cover', filename, re.IGNORECASE):
    self.has_cover = True
    self.cover_file_path = file_path  # 표지 파일 경로 저장
```

### 2. pdf_processor.py - 오른쪽 50% 자르기
```python
# 현재 썸네일이 표지인지 확인
is_cover_thumbnail = False
if hasattr(self, 'has_cover') and self.has_cover:
    thumb_filename = os.path.basename(thumbnail_info.get('pdf_path', ''))
    if re.search(r'표지|cover', thumb_filename, re.IGNORECASE):
        is_cover_thumbnail = True

if is_cover_thumbnail:
    # 오른쪽 50% 사용
    crop_rect = fitz.Rect(
        original_rect.x0 + original_rect.width / 2,  # 중간부터
        original_rect.y0,
        original_rect.x1,  # 오른쪽 끝까지
        original_rect.y1
    )
```

### 3. settings.json - 전역 설정 제거
```json
// 제거됨: "crop_left_half": true
```

## 작동 방식

1. **표지 파일 감지**: 파일명에 "표지" 또는 "cover" 포함 시
2. **오른쪽 50% 추출**: 표지 파일만 오른쪽 절반 사용
3. **일반 파일**: 자르기 없이 전체 사용
4. **우선 배치**: 표지가 있고 썸네일이 여러 개면 첫 번째 박스에 우선 배치

## 테스트 방법

```python
processor.process_files(

    qr_image=None

```
