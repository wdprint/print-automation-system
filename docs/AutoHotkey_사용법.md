# PDF 자동화 시스템 AutoHotkey 사용법

## 🚀 빠른 시작

### 1. 필수 파일 확인
- `pdf_automation_v2.ahk` - AutoHotkey 스크립트
- `print_automation.exe` - PDF 처리 프로그램 (같은 폴더에 있어야 함)
- `config.ini` - 설정 파일 (선택사항)

### 2. AutoHotkey v2 설치
- [AutoHotkey v2 다운로드](https://www.autohotkey.com/download/ahk-v2.exe)
- v2 버전이 필요합니다 (v1은 호환되지 않음)

### 3. 스크립트 실행
- `pdf_automation_v2.ahk` 더블클릭
- 트레이 아이콘으로 실행 확인

## 📌 기본 사용법

### 파일 처리 순서
1. **파일 탐색기에서 파일 선택**
   - 의뢰서 PDF (필수) - 파일명에 "의뢰서" 포함
   - 표지 PDF (선택) - 파일명에 "표지" 포함 
   - 내지 PDF (선택) - 일반 PDF 파일
   - QR 이미지 (선택) - PNG/JPG 파일

2. **프리셋 단축키 누르기**
   - `Alt+Q` : 프리셋 1 사용
   - `Alt+W` : 프리셋 2 사용
   - `Alt+E` : 프리셋 3 사용
   - `Alt+R` : 프리셋 4 사용

3. **자동 처리**
   - 파일 자동 분류
   - 선택한 프리셋으로 처리
   - 완료 알림 (소리 + 메시지)

## ⌨️ 단축키 목록

### 처리 단축키
| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Alt+Q` | 프리셋 1 | 첫 번째 프리셋으로 처리 |
| `Alt+W` | 프리셋 2 | 두 번째 프리셋으로 처리 |
| `Alt+E` | 프리셋 3 | 세 번째 프리셋으로 처리 |
| `Alt+R` | 프리셋 4 | 네 번째 프리셋으로 처리 |

### 프로그램 제어
| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Alt+S` | 설정 창 | 프리셋 좌표 설정 |
| `Alt+G` | GUI 모드 | 드래그앤드롭 창 열기 |
| `Alt+H` | 도움말 | 사용법 안내 |
| `Alt+Shift+R` | 재시작 | 스크립트 새로고침 |
| `Alt+Shift+Q` | 종료 | 프로그램 종료 |

## 📂 파일 이름 규칙

### 자동 인식 키워드
- **의뢰서**: `의뢰서`, `order` (대소문자 무관)
- **표지**: `표지`, `cover` 
- **QR 코드**: `QR`, `qr` 또는 첫 번째 이미지 파일

### 예시
```
✅ 올바른 파일명:
- (주)회사명_의뢰서_2025-01-15.pdf
- 1_표지_10mm.pdf
- QR코드.png

❌ 인식 안 되는 파일명:
- 주문서.pdf (의뢰서로 인식 안 됨)
- 커버.pdf (표지로 인식 안 됨)
```

## ⚙️ 프리셋 설정

### 프리셋이란?
각 프리셋은 독립적인 좌표 설정을 가집니다:
- 썸네일 위치 및 크기
- QR 코드 위치 및 크기
- 기타 처리 옵션

### 프리셋 설정 방법
1. `Alt+S`로 설정 창 열기
2. 상단 탭에서 프리셋 선택 (1~4)
3. 좌표 조정
4. 저장

### 활용 예시
- **프리셋 1**: 표준 레이아웃
- **프리셋 2**: 큰 썸네일용
- **프리셋 3**: QR 없는 레이아웃
- **프리셋 4**: 특수 고객용

## 🔧 설정 파일 (config.ini)

### 설정 항목
```ini
[General]
ShowNotifications=true  ; 알림 표시 여부
PlaySounds=true        ; 소리 재생 여부

[Hotkeys]
Preset1=!q  ; ! = Alt, ^ = Ctrl, + = Shift
Preset2=!w
Preset3=!e
Preset4=!r
```

### 단축키 변경 방법
1. `config.ini` 파일을 메모장으로 열기
2. 원하는 단축키로 변경
3. 저장 후 스크립트 재시작 (`Alt+Shift+R`)

## 💡 사용 팁

### 1. 빠른 작업 흐름
- 자주 사용하는 레이아웃을 프리셋 1에 저장
- 파일 선택 → `Alt+Q` → 완료!

### 2. 여러 PDF 처리
- 표지와 내지를 함께 선택 가능
- 표지는 자동으로 첫 번째 위치에 배치
- 표지는 오른쪽 50%만 자동 사용

### 3. 문제 해결
- 처리 안 될 때: 파일명에 "의뢰서" 포함 확인
- 스크립트 오류: `Alt+Shift+R`로 재시작
- EXE 찾을 수 없음: 같은 폴더에 있는지 확인

## ❓ 자주 묻는 질문

**Q: 의뢰서가 인식되지 않아요**
A: 파일명에 "의뢰서"가 포함되어 있는지 확인하세요.

**Q: 여러 파일을 한 번에 처리할 수 있나요?**
A: 네, 의뢰서 1개 + 표지/내지 여러 개 + QR 1개를 선택하고 단축키를 누르면 됩니다.

**Q: 프리셋 좌표를 변경하고 싶어요**
A: `Alt+S`로 설정 창을 열어 각 프리셋별로 좌표를 조정할 수 있습니다.

**Q: 단축키를 변경하고 싶어요**
A: `config.ini` 파일을 편집하여 원하는 단축키로 변경 가능합니다.

## 📞 문제 발생 시

1. AutoHotkey v2가 설치되어 있는지 확인
2. `print_automation.exe`가 같은 폴더에 있는지 확인
3. 스크립트 재시작 (`Alt+Shift+R`)
4. 그래도 안 되면 PC 재시작
