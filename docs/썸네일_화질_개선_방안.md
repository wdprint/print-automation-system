# 썸네일 화질 개선 방안 - 상세 진행 내역

## 문제 상황
- **핵심 문제**: 표지 PDF(1_국제무역관리자과정_표지_10.6mm.pdf)를 썸네일로 변환하여 의뢰서 PDF에 삽입할 때 심각한 화질 열화 발생
- **크기**: 썸네일은 160x250 픽셀로 의뢰서 PDF에 삽입됨
- **증상**: 텍스트가 흐릿하고 이미지 디테일이 손실됨

## 시도한 개선 방법들

### 1차 시도: 이중 리사이징 제거
**문제 인식**: 
- pdf_processor.py에서 이미지를 두 번 축소하고 있었음 (line 343-347)
- 432 DPI로 렌더링 → 320x500으로 1차 축소 → 160x250으로 2차 축소

**해결 방법**:
```python
# 이중 리사이징 제거 - 한 번에 최종 크기로
img.thumbnail((thumb_width, thumb_height), Image.Resampling.LANCZOS)
```

**결과**: 약간의 개선이 있었으나 여전히 흐릿함

### 2차 시도: UnsharpMask 파라미터 최적화
**적용 내용**:
```python
# 과도한 선명화 방지
img.filter(ImageFilter.UnsharpMask(
    radius=0.5,     # 1 → 0.5
    percent=80,     # 120 → 80
    threshold=3
))
```

**결과**: 큰 차이 없음

### 3차 시도: PNG 압축 최소화
**적용 내용**:
```python
# PDF 삽입 시 품질 보존
resized_img.save(img_buffer, format='PNG', compress_level=1, optimize=False)
```

**결과**: 파일 크기는 증가했으나 품질 개선 미미

### 4차 시도: DPI 증가 및 resize() 메서드 사용
**적용 내용**:
1. DPI 432 → 600 → 900으로 단계적 증가
2. `thumbnail()` 메서드를 `resize()` 메서드로 변경
3. 샤프닝 순서 변경 (리사이징 후 적용)

```python
# DPI 증가
dpi = self.settings.get('thumbnail.render_dpi', 900)

# resize() 사용
img = img.resize((new_width, new_height), Image.Resampling.LANCZOS)

# 리사이징 후 샤프닝
img = self._apply_image_effects(img)
```

**결과**: 여전히 개선 부족

### 5차 시도: 테스트를 통한 최적 DPI 찾기
**테스트 결과**:
- 72 DPI: 매우 흐림
- 300 DPI: 흐림
- 600 DPI: 약간 개선
- 900 DPI: 파일 크기 증가, 품질 개선 미미
- 1200 DPI: 메모리 사용량 급증 (DecompressionBombError 발생 가능)

### 6차 시도: 강력한 이미지 향상 필터 적용
**적용 내용**:
```python
# 1. 엣지 강화
img = img.filter(ImageFilter.EDGE_ENHANCE_MORE)

# 2. 강력한 언샵 마스크
img = img.filter(ImageFilter.UnsharpMask(
    radius=1.5,
    percent=200,
    threshold=1
))

# 3. 대비 향상
contrast = 1.3
enhancer = ImageEnhance.Contrast(img)
img = enhancer.enhance(contrast)
```

**결과**: 약간의 개선이 있었으나 근본적 해결 안됨

### 최종 시도: 썸네일 생성과 의뢰서 처리 분리
**접근 방법**:
- 의뢰서 PDF 렌더링은 건드리지 않음 (용량 낭비 방지)
- 표지 PDF → 썸네일 변환 시에만 초고해상도(1200 DPI) 적용

**최종 설정**:
```python
# config/settings_manager.py
"thumbnail": {
    "render_dpi": 1200,  # 표지용 초고해상도
    "contrast": 1.3,
    "sharpness": 1.5,
    "quality": 100
}
```

## 근본적인 문제 분석

### 1. PyMuPDF의 한계
- `page.get_pixmap()`으로 PDF를 래스터 이미지로 변환 시 품질 손실 불가피
- 벡터 그래픽이 비트맵으로 변환되면서 선명도 손실

### 2. 극단적인 축소 비율
- 원본 PDF: 1292 x 913 points (A4 가로)
- 목표 썸네일: 160 x 250 pixels
- 약 8:1의 축소 비율로 디테일 손실 필연적

### 3. 리샘플링 알고리즘의 한계
- LANCZOS도 극단적인 축소에서는 한계가 있음
- 텍스트와 세밀한 그래픽은 특히 품질 저하가 심함

## 추가 고려사항

### 대안 1: 썸네일 크기 증가
- 160x250 → 320x500으로 증가 검토
- 의뢰서 PDF 레이아웃 수정 필요

### 대안 2: 벡터 그래픽 유지
- PDF를 이미지로 변환하지 않고 PDF 자체를 삽입
- PyPDF2 또는 다른 라이브러리 활용

### 대안 3: 사전 생성된 고품질 썸네일 사용
- 디자이너가 미리 최적화된 썸네일 이미지 제공
- PDF 변환 과정 생략

### 대안 4: AI 기반 이미지 업스케일링
- ESRGAN, Real-ESRGAN 등 AI 모델 활용
- 처리 시간과 의존성 증가
